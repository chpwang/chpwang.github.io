Font attribution and redistribution notes
=========================================
Open Sans Condensed (300, 700) — Steve Matteson / Open Sans project.
Special Elite (400) — Brian J. Bonislawsky, Astigmatic.
The font families are made available through Google Fonts under Apache 2.0.
See Apache-2.0.txt. Upstream Fontsource distribution package license texts
are additionally copied here by tools/install-local-fonts.sh.

Source npm packages (pinned):
  @fontsource/open-sans-condensed@4.5.5
  @fontsource/special-elite@5.3.0

Fonts are intentionally stored in this directory when installed locally.
Commit these files to the PLN Git submodule before deploying; otherwise
other machines and GitHub Pages will not have the font resources.
